# CSEF 项目展示

[访问项目网站](https://lxyyyyyyyyyyyyyyyy.github.io/CSEF-Project-Page/)

Conditional State Edit Field for Low-Light Image Enhancement

作者：Yilang Liao、Xinyao Li、Ruqing Lv（South China University of Technology）。

本仓库用于发布项目介绍、实验结果、真实输出的交互对比与论文。模型实现、训练代码及权重暂未公开。

网站通过 GitHub Pages 从 `main` 分支根目录发布。修改网页或展示素材后，提交到 `main` 即可更新。

实验指标取自项目论文，速度取决于论文中的实验环境。本页面的交互对比展示预先生成的模型结果。
